# 练习数据：胚胎移植后等待期焦虑（模拟数据）

> 全部是模拟数据，只用于教学，不代表任何真实患者。

这份数据是为系列课《AI 赋能护理科研实战：从一个临床现象到一篇论文》准备的，可以拿来练习 05 卡（结果解读）：把 SPSS 风格的输出贴给 AI，看它能不能读对，再对照参考答案。文件名里的「D10」是这个演示在课件里的编号。

## 文件

| 文件 | 用途 |
|------|------|
| `等待期焦虑_模拟数据.csv` / `.xlsx` | 80 对夫妻，每行一对；xlsx 另有「变量说明」页，可以直接导入 SPSS |
| `D10_SPSS风格输出.md` | 女方 SAS 标准分重复测量方差分析，SPSS 中文版风格的输出（文本） |
| `D10_SPSS风格输出_1.png` / `_2.png` | 同一份输出的截图版，可以试试截图粘贴时 AI 会不会读错 |
| `D10_答案要点.md` | 参考答案：正确解读必须包含的数字、规范结果句、AI 容易出错的地方 |
| `基线表_Table1.md` | 按 CONSORT 格式做的基线表（不含 P 值列） |
| `make_simulated_data.py` | 生成以上全部文件（固定随机种子 20261104，结果可重复） |
| `verify_with_r.R` | 用 R 的 car 包独立复算方差分析结果 |

## 怎么练

1. 在 Kimi 新开一个对话，粘贴 [05 卡](../../prompts/05-结果解读.md) 的提示词。
2. 选「解读统计软件输出」，把 `D10_SPSS风格输出.md` 的内容贴进去（或者上传两张截图）。
3. 对照 `D10_答案要点.md`，看 AI 有没有读对数字、有没有掉进下面这些坑。

## 模拟设定

- 两组随机对照：干预组（夫妻共同参与的等待期护理方案）和对照组（常规护理），每组 40 对夫妻。
- 测量时点：T0 移植日、T1 移植后第 7 天、T2 验孕前；结局是女方和男方的 SAS 标准分。
- 女方均值设定：干预组 52→51→49，对照组 52→54→56；同一人三次测量的相关 0.50–0.75；夫妻同一时点的相关 0.35。
- 验孕前问卷缺失：干预组 2 例、对照组 3 例，所以重复测量方差分析按完全病例分析，纳入 75 例。

## 数据里埋好的坑

1. 球形假设不满足（Mauchly P<0.001），应该报告 Greenhouse-Geisser 校正后的结果。
2. 组别主效应不显著（P=0.067），交互作用显著（P<0.001）。主效应不显著不等于干预无效。
3. SPSS 显示「.000」，看 AI 会不会改写成 P<0.001。
4. 完全病例分析丢了 5 例。线性混合模型可以纳入全部数据，可作为敏感性分析（结果见答案要点）。
5. 男方数据和女方数据不独立，不能合并成一个样本分析。

## 复现与核验

下面的命令都在本文件夹里运行（macOS / Linux 终端）。

```bash
python3 make_simulated_data.py
```

```bash
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 Rscript verify_with_r.R
```

2026-10-22 核验结果：交互作用 F=11.3368、组别主效应 P=0.067、Mauchly W=0.808（P=0.00045）、GG ε=0.839、验孕前组间差 −7.63（95%CI −11.41 至 −3.86），Python 和 R 一致。Huynh-Feldt ε 两者略有不同，因为 R 的 car 包用的是 Lecoutre 修正公式，SPSS 和本脚本用的是原始公式。

Python 脚本需要 numpy、pandas、scipy、statsmodels、matplotlib、openpyxl；R 脚本需要 car 包。
