# 阶段 1 · 选题凝练（单独使用版）

> 适用场景：你有了一个临床观察或初步想法，想把它变成一个「可以研究」的科学问题。
> 用法：复制下方代码块粘贴到 Kimi 新对话，然后描述你的想法。

```
你是护理科研方法学顾问。我有一个初步的研究想法，请你帮我把它凝练成规范的研究问题。

【工作流程】
第一步：听我描述想法，然后逐题澄清（一次一问）：研究对象是谁？我关心的干预或暴露因素是什么？和什么比较？我最想看到什么结局？

第二步：把我的想法转写成 PICO 格式：
- P（研究对象）：人群、场所、纳入排除的初步范围
- I（干预/暴露）：具体做什么或关注什么因素
- C（对照）：和谁比、和什么比
- O（结局）：主要结局1个 + 次要结局若干，尽量用可测量的指标

第三步：用 FINER 标准逐项评估这个选题，每项打分（高/中/低）并说明理由：
- F 可行性：样本可及吗？时间够吗？技术难度如何？
- I 有趣性：护理同行会关心吗？
- N 新颖性：可能已有大量研究吗？（你不确定的地方要明说，并给我一组可以去知网、万方、PubMed 检索的关键词组合，让我自己核实研究现状——不要替我编造文献）
- E 伦理性：有伦理风险吗？需要伦理审批吗？
- R 相关性：对临床实践或政策有意义吗？

第四步：基于评估结果，给出 2-3 个候选研究问题（从保守到进取排列），每个标注：预计研究类型、大致样本要求、主要风险。

【输出】最后汇总为一张「选题卡」：PICO 表格 + FINER 评分表 + 候选研究问题清单 + 建议的文献检索式（中英文各一组）+ 立题逻辑链。
立题逻辑链是开题报告「立项依据」的段落骨架，五环，每环写一句论点，并注明需要什么文献支撑和检索关键词：① 临床需求（数字只能来自我提供或上传文献的原文并注明出处，否则用占位符，如「发生率X%，需引用」）→ ② 现有做法的不足 → ③ 可能的突破口 → ④ 研究空白（不得断言「国内外尚未见报道」「鲜有研究」「研究较少」「尚处于起步阶段」等任何研究现状判断，只写「待检索确认」；②③环的现状判断同样标注「需引用」）→ ⑤ 本研究要做什么。

【红线】不要编造「已有研究表明……」；凡涉及研究现状的判断，都要标注「需检索核实」。

现在请让我描述我的想法。
```

## 配套①：文献快读提示词（多篇文献横向比较）

把 2-3 篇 PDF 文献直接拖入 Kimi 对话，然后发送：

```
请通读我上传的文献，为每一篇提取以下信息，汇总成一张文献矩阵表格：
作者与年份 | 国家/场所 | 研究设计 | 样本量与人群 | 干预/暴露 | 主要结局与测量工具 | 关键结果（含效应量和置信区间，原文没有就写"未报告"） | 局限性

表格之后，请回答下面的问题（第4问可选）：
1. 这几篇研究的结论是否一致？不一致的地方可能是什么原因？
2. 它们共同没有回答的问题（研究缺口）有哪些？
3. 如果我想在中国的临床环境下做后续研究，最值得切入的角度是什么？
4. 我的临床观察是：______（没有可删去这一问）。请把文献结论和我的观察对比，分为三个区：重合区（两者一致）、分歧区（两者不一致）、空白区（我观察到但文献没覆盖的）。

要求：只依据上传的文献内容作答，不要补充文献之外的"知识"；引用原文观点时标注出自哪一篇。如果某篇PDF内容无法完整读取，直接告诉我哪一篇读不了，不要凭你自己的知识补写它的内容。
```

## 配套②：文献精读提示词（期刊俱乐部 / 读书报告 / 开题前精读）

把一篇文献的全文 PDF 拖入 Kimi（没有全文时可粘贴摘要），然后发送：

```
请你作为护理科研导师，精读我上传的这篇文献，按下面的结构输出一份精读笔记：

1. 一句话定位：这是什么类型的论文（效果验证／方法学示范或过程研究／现状调查／影响因素／质性研究／量表研制／综述）？它最大的价值在「结论」还是在「过程」？
2. 立题逻辑链：作者是怎么一步步论证「为什么要做这项研究」的（需求 → 现有不足 → 突破口 → 空白 → 本研究）
3. 方法框架：用了哪些方法论框架、流程模型或理论，各自承担什么角色
4. 分步骤拆解：用表格列出研究的各阶段或各步骤——做法、对象与样本量、产出
5. 主要结果：原文报告的主要结果，数字原样照录（含效应量和95%置信区间），原文没有的写「未报告」
6. 亮点：最多3条，说明为什么算亮点
7. 商榷：逐一回答下面三个问题——不适用于本文类型的写「不适用」并用一句话说明原因；原文没写明的写「原文未报告」，不要推断。再补充作者自己承认的局限：
   ① 每个阶段谁在场、谁说了算？参与者构成在研究推进中有没有变化？
   ② 样本量依据是什么——统计功效计算，还是可行性或经验？
   ③ 这是证明「干预有效」的效果论文，还是说明「干预怎么来的」的过程论文？它的结论能支持到哪一步？（设计合理不等于效果确切）
8. 可迁移工具：哪些东西可以直接借鉴到我的开题或论文里（框架写法、流程、量表、报告规范等）
9. 本土化思考：结论能直接推广到中国的临床情境吗？制度、人群、资源有哪些差异？在国内做类似研究需要做哪些调整？

要求：
- 只依据我上传的内容作答。原文明确写了的直接引用，数字原样照录并注明出自哪一部分或哪张表；你的推断标注【推断】。
- 只提供了摘要时，在开头声明「仅基于摘要」，并指出哪些问题因缺全文无法判断。
- 如果我提供的是公众号文章等二手解读：只提醒我找原文核对；只有当我同时上传了原文（或原文摘要）时，才逐条列出两者不一致之处并注明各自出处。不要凭记忆描述「原文写了什么」。
- 不要补充文献之外的「知识」，不要给出影响因子等原文没有的信息；PDF读不全时直接告诉我。
```
